Cap Calculation Path

For the selected model: raw subgroup weight is scaled into requested consensus weight, then non-initial models are capped by previous epoch root total multiplied by cap factor. The last point is a preview for the next epoch if the latest requested weight repeats.

Network Denominator & Next Cap

The root total at the end of an epoch becomes the denominator for the next epoch's model cap. The dashed line shows the next cap limit produced by each epoch's root total.

Cap Pressure Matrix

Pressure is requested weight divided by cap limit. Values above 100% are capped. Initial models are excluded from this matrix because cap does not apply to them.

Param Snapshot Timeline

On-chain cap factor, initial model, and model scale factors at start/end snapshots. This explains which parameters were used before the cap formula was applied.
